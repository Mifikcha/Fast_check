# Открытые вопросы Stage F2b (решения приняты консервативно, до расчётов)

1. **Общий вывод Q1.** Правило задано для стратегии; общий вывод берётся по трём лучшим стратегиям F2 (X:T1, X:T5, D:T1):
   «артефакт» — только если все три «артефакт», «сигнал настоящий» — только если все три «настоящий», иначе «частично артефакт».
   Решающие числа — разработка; контроль справочно (он открывался в F2).
2. **EPT** считается по валовой прибыли **с фандингом** (как CCR в F2); вариант без фандинга приведён рядом.
3. **Общее покрытие в Q1.** Актив исключается на баре решения, если нет марк-цены для его ближайшего бара удержания; поэтому вариант
   P в F2b может чуть отличаться от F2. Фактически покрытие марк-цен 100%, отличий нет.
4. **PM.** Из марк-цены пересчитаны только OHLC-ряды; объём, оборот (и vwap в A101), OI, фандинг и премиум — как в F2 (у марк-свечей нет объёма).
   Цель обучения — по марк-цене. Те же зёрна плацебо, BH, K, сетка α, что в F2.
5. **Q2, состав плацебо.** Всего 20% от числа реальных (как в F2), поровну 4 типа; тип 1 остаётся в пуле BH (иначе изменилось бы m),
   но не входит в итоговый FDR. Порог 10% для доли типов 3+4 среди отобранных близок к доле этих плацебо среди всех проверяемых
   признаков (~8,3%) — это отмечено в отчёте.
6. **Q2, «лаг возвращает к номиналу»:** доля |t| > 2 не выше 4,6% + 1,96 стандартной ошибки доли.
7. **Q3.** Бета актива к равновзвешенному рынку — по 180 барам до t (не включая t), минимум 90 баров; без истории — бета 1.
   Если при нейтрализации множитель одной из частей выходит ≤ 0 (или одной части нет), веса оставлены как есть (доля приведена).
   Доля потерь, объяснённая бетой = Σ min(0, бета × доходность рынка) / Σ чистая прибыль по стратегиям h = 6/18, убыточным на контроле.
8. **Q4.** Медианное |Δw| — по ненулевым изменениям весов бета-нейтральной версии на разработке. Валовой объём при частичном
   движении может быть < 1; Шарп и EPT от этого не зависят.
9. **Q5.** Вынужденные сделки — только на барах с внешневыборочным прогнозом; правило «полезен» требуется для **обоих** D (1 и 2).
   Случайная подсказка откладывает на каждом шаге с вероятностью, равной частоте откладывания моделью на этом периоде.
10. **Поправка 4 (фандинг по марк-цене):** стоимость позиции на момент расчёта = вес × марк-цена (open часовой марк-свечи в момент
    расчёта) / цена открытия бара удержания — в соглашении F2 о постоянных весах внутри бара.
