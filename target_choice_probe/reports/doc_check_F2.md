# Сверка предположений с документацией (Stage F2)

Дата проверки: 2026-10-24. Всё ниже сверено до заморозки конфига и до загрузки данных. Пункты, помеченные в задании «ПРОВЕРИТЬ», отмечены **(П)**.

|---|---|---|---|
| 1 | `kline`, интервал 60, перпетуалы | Интервалы `1,3,5,15,30,60,120,240,360,720,D,W,M`; `limit` 1–1000 (по умолчанию 200); список отсортирован **по убыванию** времени; поля: начало свечи, open, high, low, close, volume (для USDT-контрактов в базовой монете), turnover (в USDT). Окно `start`–`end` на 1000 часов отдаёт ровно 1000 свечей (пробный запрос BTCUSDT, октябрь 2021). Совпадает. | [Get Kline](https://bybit-exchange.github.io/docs/v5/market/kline) |
| 2 | `premium-index-price-kline`, интервал 60 | Только `category=linear`; те же интервалы и `limit` 1–1000; поля: начало, open, high, low, close (без объёма). Часовые свечи BTCUSDT есть с октября 2021 (пробный запрос). **Замечание:** в старых свечах встречается high < open (пример: BTCUSDT 2021-10-01 01:00). Поэтому для «среднего за бар» берём только close часовых свечей, high/low премиума не используем. | [Get Premium Index Price Kline](https://bybit-exchange.github.io/docs/v5/market/premium-index-kline) |
| 3 **(П)** | `open-interest`, интервал 1 час: интервалы, глубина, лимит | `intervalTime`: `5min, 15min, 30min, 1h, 4h, 1d` — 1 час есть. `limit` 1–200, **по умолчанию 50** (не 200, ставим явно 200). Глубина: в документации только «нижняя граница — время запуска символа», лимита глубины нет. Пробные запросы: BTCUSDT и SOLUSDT отдают часовой OI с 2021-10-01. `startTime`+`endTime` работают как окно (включительно с обеих сторон); пагинация также возможна через `cursor`, мы используем окна по 200 часов. Единица `openInterest` для USDT-контрактов — базовая монета. Документация не говорит, к какому моменту относится снимок с меткой `timestamp`; берём консервативно только снимки **строго внутри** бара (метка < конец бара). | [Get Open Interest](https://bybit-exchange.github.io/docs/v5/market/open-interest) |
| 4 | `funding/history` | Как в F1: `limit` 1–200; только `endTime` листает назад; только `startTime` — ошибка. Данных F1 в `data/clean` для фандинга нет (там только `universe.parquet`, и F1 качал фандинг лишь для 56 символов со спотом), поэтому F2 собирает фандинг сам для всех 80 символов. | [Get Funding Rate History](https://bybit-exchange.github.io/docs/v5/market/history-fund-rate); F1 `reports/doc_check.md` |
| 5 | Выплата фандинга | Выплата = ставка × стоимость позиции по марк-цене в момент расчёта. Марк-цену мы не качаем: стоимость позиции приближаем весом позиции (марк ≈ последняя цена; ошибка второго порядка). Расчёт, совпадающий с концом бара, относим к позиции, державшейся на этом баре. | [Introduction to Funding Rate](https://www.bybit.com/en/help-center/article?id=000001123) (сверено в F1) |
| 6 | Лимиты запросов | 600 запросов / 5 с на IP; при превышении HTTP 403 и пауза ≥ 10 мин. Параллельно может идти загрузка F1 (18/с), поэтому F2 берёт 12/с: вместе ~30/с, ~25% лимита. | [Rate Limit Rules](https://bybit-exchange.github.io/docs/v5/rate-limit) |
| 7 | Комиссии автора | taker 5,5 б.п., maker 2,0 б.п. за сторону — даны автором, не проверяются. | задание |
| 8 **(П)** | Формулы «101 Formulaic Alphas» (Kakushadze, 2015, arXiv:1601.00991) | PDF статьи скачан, но его текст закодирован так, что без дополнительных библиотек (их нет в общем `.venv`) не читается. Формулы сверены по **вторичному источнику**: комментариям-цитатам формул в открытом коде [yli188/WorldQuant_alpha101_code](https://github.com/yli188/WorldQuant_alpha101_code). Совпадают с тем, что было «по памяти». Найденное расхождение внутри источника: Alpha#38 в формуле `Ts_Rank(close, 10)`, а в коде `ts_rank(open, 10)` — берём формулу. Перевод на крипту: `rank` = ранг по срезу активов; `returns` = доходность бара; `vwap` = turnover / volume; формулы, где сырой уровень цены несравним между активами (Alpha#41), переведены в отношения (`sqrt(high·low)/vwap − 1`) — помечено в метаданных. Окна статьи (в днях) используются как окна в барах без изменения. Формулы с отраслевой нейтрализацией не берём. **Остаётся ПРОВЕРИТЬ по оригиналу.** | вторичный источник выше |
| 9 **(П)** | ADF (тест Дики–Фуллера), параметры | `statsmodels` в общем `.venv` нет; реализация своя: регрессия Δy на константу, y(t−1) и p лагов Δy; p выбирается по AIC от 0 до `12·(n/100)^{1/4}` (правило Шверта), как по умолчанию в распространённых пакетах. Критические значения для варианта «с константой» — асимптотические MacKinnon: −3,43 (1%), −2,86 (5%), −2,57 (10%). p-значение не считаем, сравниваем со значениями. Проверено тестом на смоделированном случайном блуждании и белом шуме. | MacKinnon (1996, 2010) — по памяти, значения стандартные |
| 10 **(П)** | Блочный бутстреп для ветки D | Используем бутстреп непересекающимися блоками (Carlstein, 1986): ряд режется на блоки по h баров, блоки выбираются с возвращением; корреляция пересчитывается по суммам внутри блоков (точно равна корреляции по склеенной выборке). Ранги внутри бутстрепа не пересчитываются (приближение, отмечено в `open_questions_F2.md`). Проверено тестом: на независимых данных SE ≈ 1/√n. | стандартная схема |
| 11 | Поправка Ньюи–Уэста | Ядро Бартлетта, веса `1 − l/(L+1)`, L = h. | Newey & West (1987), стандарт |
| 12 | Метод Бенджамини–Хохберга, поправка Холма | BH: наибольшее k с p₍ₖ₎ ≤ k·q/m, проходят все p ≤ p₍ₖ₎. Holm: пошаговая, p₍ᵢ₎·(m−i+1) с накоплением максимума. | Benjamini & Hochberg (1995); Holm (1979) |
| 13 | Ошибка годового Шарпа за 180 дней ≈ 1,4 | По формуле Lo (2002) для независимых доходностей SE ≈ √((1 + SR²/2)/T), T в годах: при SR ≈ 0 и T = 0,49 года SE ≈ 1,43. Совпадает. | Lo (2002) |
