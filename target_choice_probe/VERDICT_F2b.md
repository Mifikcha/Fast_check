# VERDICT F2b — закрывающие проверки ветки F2

**Словарь (новые термины)**

- **Отскок между bid и ask** — цена последней сделки случайно попадает то на лучшую цену покупки, то на лучшую цену продажи; цена «прыгает» без реального движения и создаёт ложный эффект «цена вернулась».
- **Марк-цена** — справедливая цена контракта, которую считает биржа (по индексу и базису); на ней нет такого «прыгания».
- **Выигрыш на единицу оборота (EPT)** — валовая прибыль / объём сделок, в б.п.; сравнивается с ценой одной стороны сделки (6,5 б.п. в S1).
- **Бета-нейтральность** — чувствительность портфеля к движению рынка в целом равна нулю.
- **Зона без сделок** — позиция меняется, только если новая цель отличается от текущей больше порога; мелкие изменения игнорируются.
- **Перестановочное плацебо** — признак, у которого значения перемешаны между активами внутри каждого бара: распределение сохраняется, связь с активом ломается.
- Остальные термины (IC, BH, FDR, плацебо, walk-forward, Шарп, CCR, контроль) — как в `VERDICT.md` F2.

**Ответы** (решающие числа — внешневыборочная разработка; контроль уже открывался в F2, поэтому на нём подтверждаем только знак и порядок величины)

1. **Q1, отскок:** сигнал настоящий. Лучшая по валовому Шарпу стратегия h = 4 ч на марк-цене — X:T1: Шарп S0 2.14
   (90% ДИ 1.16 … 3.05; на контроле 2.73), EPT 1.44 б.п. против 1.52 б.п. по ценам сделок.
2. **Q2, плацебо:** отбор BH + топ-20 контролирует ложные находки (максимум доли перестановочных плацебо
   среди отобранных 0.7%); BH без ограничения контролирует (1.6%).
   Перестановочные плацебо проходят BH не чаще 5.9%, сдвиг по времени — в среднем 26.3%.
   Лаг Ньюи–Уэста = h занижает ошибку: h=6 (T1/T3/T4): доля |t|>2 при лаге h = 9.7%; ни один лаг до 4h не возвращает к номиналу; h=6 (T5/T6): доля |t|>2 при лаге h = 6.0%; к номиналу возвращает лаг 1h = 6; h=18 (T1/T3/T4): доля |t|>2 при лаге h = 10.8%; к номиналу возвращает лаг 4h = 72; h=18 (T5/T6): доля |t|>2 при лаге h = 9.0%; к номиналу возвращает лаг 2h = 36.
3. **Q3, бета:** бета объясняет 33% потерь стратегий h = 6/18 на контроле; после бета-нейтрализации у части стратегий h = 6/18 валовая альфа > 0 (`reports/q3_beta.md`).
4. **Q4, оборот:** **закрыть** — максимальный EPT на сетке 4.31 б.п., в 1.5 раза ниже издержек 6,5 б.п.; безубыточность при издержках X:T1 4.31, D:T5 3.01 б.п. на сторону.
5. **Q5, тайминг:** **пользы для тайминга не обнаружено** (средняя экономия на сделку D=1: разработка +0.37, контроль -0.86 б.п., D=2: разработка +0.77, контроль -0.08 б.п.).

**Итог ветки F2: ЗАКРЫТЬ.**

**Три результата для диссертации**

- *Сигнал меньше издержек на масштабе часов.* После проверки на отскок лучший валовой сигнал на 4 часа даёт 1.4 б.п. на единицу
  оборота, а одна сторона сделки taker стоит 6,5 б.п.; даже снижение оборота зоной без сделок поднимает EPT максимум до
  4.3 б.п.
- *Высокий IC не означает больше денег.* В ветке X у ранговой цели T4 самый высокий внешневыборочный IC (h = 1/6/18: 0.051/0.073/0.080
  против 0.031/0.034/0.046 у T1), но после бета-нейтрализации её валовая альфа отрицательна
  (h = 6: разработка -12.6%, контроль -53.9% годовых), а у T1 — +15.0% и +34.6%.
- *Плацебо для сравнения активов должно ломать связь с активом, а не со временем.* Сдвиг по времени ≥ 60 суток проходит BH в 26%
  случаев (устойчивые свойства активов переживают сдвиг), перестановка между активами — не чаще 5.9%.

**Поправки к F2** (`reports/F2_corrections.md`): регулятор волатильности — не подтверждён, на контроле вредит; FDR 6,7% — одна пара, фильтр
«топ-20»; T3 = T1 на h = 6/18 (Холм по 19 сравнениям, минимум p = 0.17); фандинг по марк-цене меняет годовой
фандинг не более чем на 8.7 б.п.

**Ограничения.** Контроль уже открывался в F2; смещение выживших; синтетическая модель вынужденных сделок (Q5); не учтено влияние объёма на цену;
исполнение лимитными заявками не моделируется.
