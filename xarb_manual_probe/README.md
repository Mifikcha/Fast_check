# Stage X2A — бумажная проверка ручного арбитража

Приносят ли спреды скринера деньги человеку, который входит руками с задержкой в десятки секунд? Две и более недели записываем рынок по публичным API и считаем сделки по заранее записанному правилу. Никаких ордеров, переводов и ключей.

Итог будет в `VERDICT_X2A.md`. Правила заморожены в `configs/stageX2_frozen.yaml`, хеш — `logs/frozen_hash.txt`, все версии и запуски — `logs/attempts.csv`.

## Что нужно от владельца

**Компьютер включён и в сети.** Запись идёт сама, окно не нужно. Что было выключено, попадёт в `logs/gaps.csv`; если пропусков больше 10% времени, запись продлевается.

Включить автозапуск (один раз, права администратора не нужны):

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install_task.ps1
```

Задача `Fast_test_X2_recorder` стартует при входе в систему и каждые 5 минут; если запись уже идёт, новая копия сразу выходит.

Проверить, что запись жива:

```powershell
Get-Content logs\heartbeat.txt     # время в секундах, обновляется раз в минуту
Get-Content logs\recorder.log -Tail 20
Get-Content logs\gaps.csv -Tail 20
```

Остановить: `Disable-ScheduledTask Fast_test_X2_recorder`, затем завершить `pythonw.exe` в диспетчере задач.

Если появился файл `logs/STOPPED_DISK`, значит на диске осталось меньше 25 ГБ и запись остановилась сама. Освободите место и удалите этот файл, задача запустится заново.

## Порядок расчёта

Из папки `xarb_manual_probe`, Python общего `.venv` репозитория:

```
python scripts/run_x2.py freeze                # до первого расчёта; изменение: freeze --reason "..."
python scripts/run_x2.py weekly                # описание недели, без сделок контроля
python scripts/run_x2.py dev                   # после 7 полных дней: сетка 54 варианта, выбор на D = 60 с
python scripts/run_x2.py open-holdout          # ОДИН раз, не раньше 14 дней записи
python scripts/run_x2.py holdout               # ОДИН расчёт выбранного варианта
python scripts/run_x2.py verdict               # VERDICT_X2A.md
python -m pytest tests -q
```

## Что где

| папка | что |
|---|---|
| `xmp/venues.py` | адаптеры 13 бирж скринера: инструменты, цены, фандинг, стаканы |
| `xmp/recorder.py` | фоновая запись, кандидаты, пропуски, запас диска |
| `xmp/match.py` | один актив на разных биржах, категории пар |
| `xmp/paper.py` | бумажная сделка: задержка, ноги по очереди, выходы, ликвидация, маржа |
| `xmp/store.py` | чтение сырых файлов |
| `xmp/evaluate.py`, `xmp/report.py` | метрики, выбор, контроль, вердикт |
| `data/raw/` | записанные данные, в git не идут |
| `reports/` | сверка документации, качество данных, план объёма, недельные отчёты |
